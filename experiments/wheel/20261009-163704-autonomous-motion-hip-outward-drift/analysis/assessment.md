# 1009-01 双轮实机评估

## 自主运动与抖动

推断策略段机身 roll 为 +1.13°～+2.96°，pitch 为 −5.73°～+4.67°；没有持续增大的机身倾角。左右髋速度 RMS 为 0.02484/0.02528 rad/s，峰值 0.26252/0.25031 rad/s。这支持本段没有复现 1002 的剧烈髋关节振荡，但不构成长时间或全工况稳定验证。

与 1003 的前 36.74 s 做等时长描述性比较，髋速度 RMS 从 0.03900/0.03781 降至本次 0.02484/0.02528；输入指令、扶持、接触和试验条件不同，不作为受控性能提升证据。1003 同等时长末端实际髋约 +0.46°/−0.44°，本次约 +1.62°/−1.04°，外偏并未消除。

本次记录前向指令 0～0.4763、转向指令 −0.5000～+0.4072，没有倒退指令覆盖；约 55.7% 策略帧的前向/转向指令同时为零。转向指令与机身 gyro Z 以 2 Hz 低通后相关系数约 0.82，0～1 s 延迟扫描最高约 0.91（0.08 s），说明转向响应方向和时序较一致。这不是角速度误差或控制带宽鉴定。

轮目标峰值右/左 10.80/10.35 rad/s，实际峰值 7.42/6.47 rad/s；速度目标与反馈 RMSE 为 2.13/2.34 rad/s。轮速同时包含平衡和转向动作，不能仅凭这个差值判定性能不合格。没有独立里程计，无法核实实际行进速度、距离、侧滑和直行偏航精度。零指令不等于机器人或轮子必然完全静止。

## 双髋慢偏与受力

所有角度均为编码器坐标，未验证等同机械垂直零位。下表每行取 2 s 均值：

|阶段|右实际/左实际|右目标/左目标|右/左报告力矩|
|---|---|---|---|
|策略前最后 2 s|−1.83° / +1.54°|0° / 0°|约 +4.93 / −4.45 Nm|
|策略开始后前 2 s|−1.14° / +1.27°|约 +3.84° / −2.84°|约 +7.64 / −6.60 Nm|
|策略结束前最后 2 s|+1.62° / −1.04°|−10.08° / +10.24°|约 −18.54 / +17.56 Nm|

精确均值以 metrics.json 为准。相对策略前，右髋变化约 +3.45°、左髋约 −2.58°。URDF 两髋转轴均为负 X，轮心低于髋部，在该坐标约定下，上述变化使两侧轮心相对机身向外偏。若实际机构与 URDF 不一致，绝对外偏量还需实测确认。

启动前髋目标为零，但反馈不在零位；启动初期目标与实际均向外侧变化。随后目标反向，实际却继续慢偏，说明不是全程“策略直接命令腿向外张”。去掉启动前 4 s 后线性趋势：实际右 +0.051°/s、左 −0.046°/s；目标右 −0.308°/s、左 +0.278°/s。应同时处理策略目标慢偏和实际负载下跟踪问题。

后段实际减目标约 +11.70°/−11.27°。髋 kp=90、kd=3 时，按目标与反馈计算的 PD 力矩与板端报告力矩高度一致（r约 0.9999，平均绝对差约 0.17/0.18 Nm），支持持续修正需求增大的判断。板端 tau_now 是估计值，不是独立扭矩传感器，不能据此确认实际输出扭矩、无饱和或机械力矩标定正确。

74.78–79.78 s 的近 5 s 零指令停留期间，平均实际髋仍约 +1.33°/−0.88°，目标约 −5.70°/+6.09°；后续零指令段实际约 +1.57°/−1.36°，目标约 −9.26°/+8.98°。因此偏置不只是转向时的瞬时姿态需求，也没有在本次零指令停留期间恢复初始姿态。

按当前 URDF 刚体模型，以末段大腿/小腿角固定、只替换髋角，相对启动前估算右轮向外约 27 mm，左轮约 20 mm，总体相对轮距变化约 47 mm。它不是实测地面轮距、位移或弯曲量。长腿会放大小角度的视觉偏斜；机械弯曲可进一步叠加，但编码器无法单独测出弯曲。

末段大腿实际约 +41.6°/−42.5°，小腿约 −9.6°/+11.2°（85.6–92.34 s 均值）；对应目标大腿约 +35.3°/−36.2°、小腿 −5.9°/+7.3°。持续跟踪偏差并不限于髋部，左脚踝与右脚踝姿态也不完全对称，需结合承载/接触分析，不能只用一个固定髋零位偏置解释全部现象。

## 原因判断与下一步只读核查

已确认的现象：启动前有静态髋误差；运动中双髋实际慢外偏；策略目标持续朝相反方向加大；报告修正力矩随之增大；零指令期间偏差仍在。

优先待验证：承载后机构/接触几何、腿部刚度、关节零位和力矩能力与训练模型是否匹配。策略目标可能是在补偿越来越大的误差，也可能体现策略自身闭环慢偏；没有观测/动作记录或受控对照，不能区分两者。仅凭这一包不能认定机械弯曲、力矩限幅、PD不足、零位错误或训练奖励任一项为唯一原因。

代码的 ComputeLWOutput 按 action×scale+default 每帧生成绝对目标，没有显式累加上一帧关节目标；这降低了“主机增量积分直接积出偏移”的可能性，不排除带动作历史的策略在闭环中产生慢偏。不在本次评估中修改增益、偏置或动作限制。

下一步先对照训练侧同策略的零位、承载形变、摩擦/接触及执行器参数，并核对板端实际增益、力矩/电流限制和标定；现有 bag 缺少电流、电压、温度、限幅、FSM、原始策略观测/动作与精确松手事件。这些证据比直接试改髋目标或增益更能区分根因。任何新增实机操作或代码改动，另行说明方案并取得批准。

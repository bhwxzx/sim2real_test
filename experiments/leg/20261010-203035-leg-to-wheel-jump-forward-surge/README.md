# 腿转轮跳跃切换与落地前冲（2026-10-10）

## 现场与结果

用户在吊绳松弛条件下扶稳初始双足位姿，在双足策略启动前不久松手，全程保持零前进/转向指令。LegToWheel腾空切换，双轮落地后持续前冲，吊绳随后拽住机器人，再由用户进入GetDown。

状态顺序为 Leg→LegToWheel→Wheel→GetDown→Passive。转换段约170步；Wheel接管至GetDown约0.160秒，采样到8组不同控制目标，最合理估计约8个策略步。50Hz bag未记录策略计数器，不能声明绝对精确步数。

大轮速首先出现在转换策略内，目标峰值约17rad/s、反馈峰值约15–16rad/s。转换末端姿态偏离参考，Wheel接管脚踝目标跳变约25°/40°，值得重点追查。接触/吊绳受力事件未同步记录，尚未唯一确定原因；吊绳介入后的大姿态变化不能当作自主摔倒证据。完整报告见[assessment.md](analysis/assessment.md)，报告原文逐字节保留，其中“未提交推送”描述的是分析完成时的历史状态，本场现已归档。

## 最新现场确认与结论

用户确认：两轮流程与前次相同，策略测试期间确保没有吊绳干扰；轮式接管后轮子着地、脚板离地；两轮均无非预期前冲，结束均主动GetDown，最后倾倒放置到地面。第二轮有主动前进输入。

用户另明确确认：**2026-10-10 上次异常由吊绳中途拉拽导致**。本次以这一现场确认作为评估前提，将上次作为吊绳外力干扰场次，保留其曲线作过程对照。此更新不改写旧报告当时的推断过程；上次没有同步受力/接触事件，无法从bag独立给出拉拽的精确时间。

两轮都完成约3.4秒转换，并进入持续的双轮控制；Wheel段分别约4.92秒、8.07秒，之后用户GetDown。这两轮支持“无吊绳干扰时可完成转换并维持短时间双轮控制”的结论。第一轮是零指令对照且末端衔接更好；第二轮包括主动前进测试，保留较大的右脚踝瞬态，接管姿态波动更大，但无现场报告的非预期前冲。

不能仅凭这些短段记录评定跳高、落地冲击、前进速度跟踪精度或长期稳定性。以下按录制顺序分别评价。

### 转换与末端衔接

转换段仍有明显动态运动：俯仰约-17.55°～+7.15°、横滚-0.53°～+3.75°。轮速反馈绝对峰值为右13.99、左6.16rad/s；目标绝对峰值为右13.18、左10.77rad/s。轮速有方向反转，峰值主要在快速转换中出现。

转换最后采样点，轮速均约-0.011rad/s，已接近反馈零点；大腿、膝和脚踝也更接近参考终态：

| 髋 | 0 / 0 | +1.48 / -0.67 |
| 大腿 | +42.00 / -42.00 | +43.38 / -42.76 |
| 膝 | -10.00 / +10.00 | -12.71 / +11.68 |
| 脚踝 | 0 / 0 | +4.78 / +3.92 |

Wheel接管的脚踝目标跳变为右-5.96°、左-6.01°；接下来0.14秒实际脚踝变化约右-9.31°、左-6.86°。这比10月10日绳拉干扰场次约25°/40°目标跳变、35°/55°实际快速变化小得多。对照只说明过程差异，不能脱离已确认的现场外力条件进行严格同条件因果比较。

### Wheel效果

4.92秒内，机身俯仰约-1.41°～+3.01°，横滚+1.38°～+2.78°，没有出现上次干扰场次的持续快速偏转。右/左实际轮速峰值约3.59/3.29rad/s，目标峰值约6.05/5.88rad/s。

零指令下仍有往复轮速和平衡姿态调整，因此不能把该段描述成绝对静止。末2秒髋实际平均角约右+0.74°、左-0.20°，大腿约+43.89°/-42.82°、膝约-11.29°/+9.98°、脚踝约-1.99°/-0.21°。该短窗口未见持续扩大到前次严重偏斜的状态，不足以评定长时间髋漂移是否解决。

总体：本轮在零指令、无吊绳干扰条件下完成转换，末端姿态与轮速收敛较好，接管突变明显减小，维持约5秒轮式控制后由用户结束，是本次两轮中更好的静态对照。

## 第二轮：152441

### 阶段与主动输入

| 阶段 | 首个对应目标样本时间 | 持续时间 / 采样输出 |
|---|---|---|
| Leg站立策略 | 15:25:59.309 | 3.259725秒 / 163帧 |

| Wheel策略 | 15:26:05.968 | 8.065611秒 / 403帧 |

| 收腿目标达到终点 | 约15:26:17.017 | 精确Passive进入未直接录制 |

前进输入在bag相对时间44.615～46.135秒、46.475～47.715秒分两段出现，最大原始control.x为0.303110；共140帧，其中43帧在转换末段、97帧在Wheel段。用户确认主动操作。侧向和转向输入保持为零。

这些是发布器原始输入值，不是独立测量的机身速度。参考配置中的LegToWheel没有commands观测项，转换观测由动作参考、锚点姿态、角速度、关节与previous action构成；转换段出现的前进输入不等于它直接进入了转换网络。Wheel则包含commands观测，接管后的响应必须结合主动输入解释，不能与第一轮全程零指令完全等同。

转换前最后1秒俯仰约-3.41°～-3.40°、横滚约0.41°～0.44°，进入转换前姿态同样稳定。

### 转换末端仍有右脚踝偏差

转换段俯仰约-18.20°～+6.91°、横滚-0.71°～+4.57°。目标轮速绝对峰值约右17.67、左8.89rad/s，实际峰值约右13.92、左8.43rad/s。这些大轮速仍存在，不能说新版测试已消除转换轮速瞬态。

转换末端：
- 大腿实际右+40.66°、左-37.39°，膝右-13.82°、左+8.64°，接近参考的程度总体好于旧绳拉干扰场次。
- 脚踝实际右+24.10°、左-8.40°；对应转换目标右+23.23°、左-7.54°。尤其右脚踝仍未回到参考零位，而且实际基本贴合该时刻的策略目标，不能单纯解释成电机追不上零位目标。
- 末端实际轮速约右-1.40、左+2.45rad/s，没有像第一轮一样回到近零。

Wheel接管脚踝目标跳变右-30.78°、左+10.29°；0.14秒内实际变化约右-41.42°、左+11.87°。机身俯仰同期约-0.70°→+2.21°。本轮保留了明显的右脚踝交接瞬态，但用户确认无非预期前冲。

### Wheel效果

约8.07秒内，俯仰约-3.99°～+4.49°，横滚+0.20°～+4.00°；实际轮速峰值约右8.71、左8.85rad/s，目标峰值约右13.53、左12.98rad/s，主要集中在接管后的短时响应中。该窗口同时包含主动前进输入和平衡恢复，没有机身线速度，不能把最高轮速直接称为失控前冲，也不能用它计算实际前进速度或距离。

前进输入已在相对47.735秒附近回零；后段仍有轮速往复。在最后2秒，指令为零，俯仰约-1.35°～+2.53°、横滚+1.30°～+2.14°；髋实际均值约右+1.17°、左-0.46°，大腿+41.34°/-41.22°、膝-9.30°/+9.74°、脚踝-2.13°/+0.36°。接管后脚踝最终恢复到接近轮式站姿的小角度区域。

总体：本轮完成无吊绳干扰转换并继续响应主动输入，维持约8秒轮式控制。较第一轮，右脚踝末端偏差和接管瞬态、机身姿态范围均更大；虽然没有非预期前冲，该差异仍应记录为复现一致性有待提高。

## 两轮共有的动态跟踪现象

两轮在转换的1～2秒阶段，右/左膝目标跟踪误差RMS分别约：
- 第一轮33.32° / 33.97°；
- 第二轮33.36° / 34.69°。

这一窗口的瞬时绝对峰值达到约右78°、左88～90°。目标迅速变化而反馈存在明显不同步，现象在两轮都出现；不能因为最终可站稳就将高速过程的关节跟踪质量评价为已经贴合参考。现有bag无法独立分解负载、执行器动态、策略目标变化、反馈延迟及机械因素的贡献，也不能直接证明扭矩/电流饱和。

当前关节effort来自电机板报告的motor_tor_now；target.effort是发布器用初始化配置生成的PD估计，并非逐帧实际下发力矩。bag没有kp/kd、电流、总线原帧或独立力矩测量，不用这两个字段宣称执行器已经饱和。

## GetDown与最终放地

两轮第一条GetDown目标起，双轮目标速度都为零，之后一直保持零。非轮关节约3秒向收腿目标插值；完成收腿目标的时刻不等于实际关节已达到该姿态，也不能直接用它精确定位Passive进入。

GetDown前，第一轮俯仰约+2.00°、第二轮约+0.37°；随后机身转到最终约62.66°、61.50°。这与用户确认的最后倾倒放置到地面相符，单独归类为退出/放地过程，不作为Wheel运行中的自主失稳。放地的外力介入和接触时刻没有同步记录，因此不评价其动作质量。
